# 审美原则

Warm Paper 的参照物是排版良好的学术期刊和杂志内页，而不是商业路演 PPT。下面每条原则都附了理由，遇到规则没覆盖的情况时，按理由推断。

## 1. 克制的颜色

- 背景 `BgPaper #FAF8F5` 是带一点暖意的纸白。纯白在投影上刺眼，暖白更接近印刷品。
- 正文 `InkMain #18181B` 接近黑但不是纯黑，和暖白背景对比柔和，长时间阅读不累。
- 次要信息（副标题、图注、批注、已弱化的旧方法）用 `InkMuted #71717A`。层级靠颜色深浅区分，而不是靠字号跳变。
- `AccentTerra #C85A32` 陶土色是**唯一**的强调色。它用在：标题分隔符 ｜、卡片左竖线、条目符号、步骤编号、`\key` 关键词、表格高亮列、底栏当前章节。观众的视线会被这个颜色引导，所以每页只给它 1–4 个落点。
- `CardSand #F0ECE1` 是卡片底色，比背景深一档；`BorderWarm #D6D1C7` 是 1pt 细边框和分割线。卡片和背景的差别很小，这是刻意的：卡片用来分组，不用来吸引注意。

不要加第二个强调色。需要表达"好 / 坏"对比时，用陶土色表示新方法或结论，用 `InkMuted` 表示旧方法或背景，而不是红绿对比。

## 2. 扁平和细线

所有容器都是扁平色块加 1pt 细边或 2.6pt 左竖线。没有阴影、圆角、渐变、立体效果。理由：装饰会和内容抢注意力，而学术汇报的内容本身就密集。

左竖线（`callout`、`takeaway`）表示"这是一条定义、背景或结论"，比四边框的 `warmcard` 更轻、更像正文旁注。

## 3. 字号层级少而稳定

整套只有七档字号：帧标题 15pt、副标题 12.5pt、卡片标题 9.5pt、正文 9pt、密集正文 8pt、批注 7pt、图注 6.5pt。中文行距约为字号的 1.4 倍，比 LaTeX 默认的 1.2 宽，因为汉字笔画密，行距紧了会糊成一片。

不要为了塞内容把字号降到 7pt 以下的正文。内容装不下就拆页。

## 4. 双语标题

标题格式是 `English Title ｜ 中文副标题`：英文是正式标题，Title Case，粗体；中文副标题用灰色常规字重，帮助中文听众快速理解。陶土色竖线 ｜ 把两者分开。标题下面一条 0.4pt 暖灰细线，和正文隔开。

## 5. 每页一个论点

一页只回答一个问题。判断标准：能否用一句话说出这页想让观众记住什么。说不出来就是内容太多，或者没想清楚。这句话通常就是 takeaway 的内容。

信息量的参考上限：正文约 260 个汉字、6 张卡片、1 张主图、1 个 takeaway。

## 6. 图是主角

有图的页面，图占页面宽度的 50–60%（左图右文）或整宽（上图下卡）。图注统一 6.5pt 灰色，写清"图在说明什么"和"来源"。不要裁剪或拉伸论文原图；需要强调图中某处时，在旁边卡片里用文字说明，而不是在图上画红圈。

## 7. 对齐和留白

- 左右边距 0.9cm，所有内容从同一条左边线开始。
- 卡片间距 5pt，栏间距由 `columns[onlytextwidth]` 的剩余宽度决定（列宽之和取 0.96–0.97）。
- 并列卡片必须等高（给第二个可选参数固定高度）。高低不齐是最容易让页面显得粗糙的问题。
- 底部批注 `fignote` 用 `\vfill` 推到底栏上方，和正文之间自然留出空白。

## 禁止事项

| 不要 | 原因 | 改用 |
|---|---|---|
| beamer 默认主题、block、alertblock | 圆角渐变和整体风格冲突 | `warmcard` / `callout` |
| 红绿蓝等命名颜色 | 破坏单强调色体系 | `\key` / `\muted` |
| 每页 5 处以上强调 | 视线无处落脚 | 留下最重要的 1–4 处 |
| 加粗整句话 | 等于没强调 | 只加粗关键词 |
| emoji、图标、剪贴画 | 学术场合显得轻浮 | 文字或步骤编号 `\stepnum` |
| 动画、逐条出现 `\pause` | PDF 分发时变成重复页 | 一页一个状态 |
| 居中排版的正文段落 | 不易阅读 | 左对齐，只有公式和陈述页居中 |
| 把图缩到很小来塞文字 | 图看不清 | 拆页 |
