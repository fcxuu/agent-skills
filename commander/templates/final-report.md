# Final Report Template

Use for complex or delegated tasks; shorten proportionally for simple work. Write the actual report in the **user's language**.

```text
Outcome
- <What was delivered and exact file paths/links>

Work Split & Integration
- <What the Commander handled vs. scripts/workers, if any>
- <How handoffs or conflicts were resolved>

Verification Evidence
- <Criterion or check>: Pass / Fail / Not verified / Blocked — <observed evidence>

Effort & Rework (only if accurately observed)
- <Elapsed time, iterations, or measured cost; omit or state unknown if not measured>

Open Issues, Risks & Next Actions
- <Material limitations, blockers with resume conditions, or required user decisions; otherwise "None">
```

Never leave a blank section to imply success. Never present estimated cost as measured fact.
