# 01 · 旧版 OCR 指南（兼容索引）

> **已由文档摄取规范（`references/01-ingestion.md`）取代。** 此文件仅保留供旧版链接/外部引用定位，不作为新任务的规范来源。新任务应以文档摄取规范（`references/01-ingestion.md`）的工具无关分级摄取、文件形态路由、探针与验收门槛为准。下文为 v0.1 历史文本。

## 目标

将同一课程的多份课件组成可追溯的源材料集。每份 PDF/PPT/讲义输出**一个完整的 OCR Markdown 文件**；不要为节省 token 强制按小节切割 OCR 原文。笔记生成时再按页码、标题或段落按需读取。

## 动态工具发现

1. 在当前 Agent 环境发现可用的 MCP 工具，查找小米 OCR 的真实工具接口；读取实际参数、输入限制和可支持格式。
2. 支持什么就处理什么；不能假定支持 PDF、PPTX 或任意文件路径。若必须先把 PPT 转换为 PDF/图片，先确认有可用且不会损坏原资料的转换能力；记录中间步骤。
3. 可先对一小段材料试运行，确认输出中公式、页序、图片信息是否可用，再批量处理。
4. 接口不可用、某文件不支持、OCR 失败、资料不可访问时，记录原始文件、错误和受影响范围到 QA，README 标注失败，不虚构 Markdown 或图片。

## 保存与溯源

- 在课程目录中使用 `raw-markdown/`；建议按原课件的安全文件名保存，例如 `raw-markdown/4知识图谱技术原理（下）.md`。
- 为对应 OCR 文件记录原始源课件路径、页码/幻灯片编号映射（若能获取）、图表来源、转换异常。不要随意覆盖原始识别产物；从 PDF/PPT 核对确认的纠错应在 QA 中留下原值、修正值与对应位置，并在笔记生成时应用已证实的校正。
- OCR 文本中的“公式看起来可读”不等于公式准确。优先检查上下标、分式、矩阵、负号、逻辑量词、图表数值及页码错位。
- 原始课件仍是第一手依据；OCR 错误不应扩散为教学错误。保留文件和来源映射，方便后续强 Agent 接手。

## 图片保留

若 OCR 返回图片位置/链接，核验对应文件是否存在并可读。无法返回图片时，在具备文件/页面图像访问能力下从源材料提取。可可靠提取的原始图表尽量归档，但仅在最终教学讲解中精选重要图。不能仅凭图题或 OCR 文本凭空补齐含数据的原图。详见图片规范（`references/04-images.md`）。

## 索引及失败处理

每份源材料在 README 中登记：源文件、OCR 文件、识别状态、必要的页码/章节指针。对没有成功 OCR 的资料，报告未处理部分和失败原因，继续其他独立源文件；如果阻断了前置知识，要在相关依赖处标记风险。不要把 OCR 不可用等同于已完成笔记。
